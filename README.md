# 质检承诺边界

**[在线试用 → https://bianwuwei.github.io/vision-promise-boundary/](https://bianwuwei.github.io/vision-promise-boundary/)**

对外承诺检测速度／误报／节拍前，先跑一遍拒单与边界清单。

面向：**厂老板、交付、销售**（谈视觉／质检落地时用）。

---

## 这不是 YOLO Demo

市面上不缺「再训一个检测模型」的演示。落地卡点往往在别处：

- 客户要「检测速度」承诺，产线节拍数字还没对齐；
- 误报代价是停线／客诉，手里却没有近两周样本表；
- 宣传稿已经写好脱敏截图，客户从未确认能否上公众号；
- 无人批红线，交付口头答应了节拍内完成。

本仓库是一个**开源小工具**：把上述边界写成可编辑规则，输出「可承诺／暂缓／明确拒单」三张清单。  
它不训练模型、不接摄像头、不做 agent——只帮你在报价与宣传之前，先把话收干净。

---

## 怎么用

1. 打开 [GitHub Pages 试用页](https://bianwuwei.github.io/vision-promise-boundary/)。
2. 左侧勾选／填写当前谈单场景（节拍、速度承诺、误报代价、样本、脱敏、红线等）。
3. 右侧即时得到三张清单；可点 **复制 Markdown** 贴进纪要或评审。
4. 需要演示「踩雷」时，点 **危险承诺预设**——会填入一组危险答案并触发拒单。

本地预览（任意静态服务器即可）：

```bash
cd docs
python3 -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080/
```

站点放在 `docs/`，与 portfolio 相同：GitHub Pages → `main` / `/docs`。

---

## 规则可编辑

规则在 [`docs/rules.json`](docs/rules.json)，每条包含：

| 字段 | 含义 |
|------|------|
| `id` | 规则编号 |
| `when` | 条件（`all` / `any` + `eq` / `neq`） |
| `outcome` | `allow` \| `defer` \| `reject` |
| `message` | 中文说明 |

改完保存，刷新页面即生效（无需构建）。引擎在 `docs/assets/app.js`。

v0.1 内置规则覆盖（节选）：

1. 误报率未与产线节拍对齐前，不单独对外承诺「检测速度」→ 拒单／暂缓  
2. 无近两周误报样本 → 暂缓对外案例数字  
3. 客户未确认脱敏截图可否上公众号 → 暂缓，不写进宣传承诺  
4. 缺节拍数字却承诺节拍内完成 → 拒单  
5. 支付／改产线参数类 → 提示另走审批  
6. 无人批红线、高误报代价无样本、未跑实验等 → 对应暂缓或拒单
